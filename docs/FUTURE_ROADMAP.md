# Template Roadmap

## Required Before Publication

1. Add `scripts/setup-template.sh`.
2. Add Apache License 2.0, contributing, and security documents.
3. Add GitHub Actions and dependency update automation.
4. Document optional Ktor-based shared networking.
5. Add final Android and iOS application icons with documented licensing.
6. Run the final identity, secret, binary, and residual-reference audit.
7. Export into a new Git repository with no history from the source application.

Each item must be completed as a small, independently validated iteration.
