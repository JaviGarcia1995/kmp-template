# Project Context

This repository is becoming a public Kotlin Multiplatform starter template for Android and iOS.
Architecture is the primary example; product functionality is intentionally small.

## Included Sample

The notes feature demonstrates shared Compose UI, typed navigation, MVVM with `StateFlow`,
a domain repository contract, SQLDelight persistence, Koin wiring, platform providers, and tests.

## Structure

```text
shared/
  domain/
  data/
  presentation/
  ui/
  navigation/
  database/
  di/
androidApp/
iosApp/
```
